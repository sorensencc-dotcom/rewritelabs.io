**Industry & Architecture Takeaways:**
1. **Treat Every MCP Server as Part of the Trust Boundary:** A single compromised server steering an agent into misusing its other tools 78.3% of the time means tool permissions cannot be granted per server in isolation. Short-lived, narrowly scoped tokens, issuer validation, call-time credential fetches, and an identity-aware gateway with audit logs limit how far one bad server can reach.
2. **Design Long-Running Agents Around Explicit Primitives:** Event inboxes, timers, memory, permissions, and outboxes give always-on agents clear points to enforce policy and observe behavior, and protocols like Poppy move customer consent into standard OAuth controls instead of bespoke integrations.
3. **Measure Efficiency Claims End to End:** 4-bit training, a $4,200 165M-parameter model, and a 1.77-second on-device reasoning model all argue for cheaper inference and training, but the gains are reported against specific baselines and benchmark suites, so validate them on your own workloads and report uncertainty before adopting them.
