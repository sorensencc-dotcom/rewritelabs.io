**Industry & Architecture Takeaways:**
1. **Eliminate Upfront MCP Schema Bloat via Deferred Tool Search:** Loading dozens of full MCP JSON schemas on every turn imposes a 40x token tax (59,417 tokens vs. 1,421 for CLI on Sonnet 5.5). Agent harnesses with shell access should default to CLI invocations and lightweight skills, while shell-less environments should adopt deferred Tool Search to keep upfront tool definitions under 600 tokens.
2. **Harden Partial-Network Agent Sandboxes Against DNS Spoofing & Shared IPs:** Perplexity's SPACE red-teaming proves that VM-host isolation holds, but partial-network allowlists fail when root-privileged agents can craft `SOCK_RAW` DNS responses or pivot through shared CDN IPs. Production sandboxes must drop raw-socket privileges, pin upstream DNS at the gateway, and filter egress by verified SNI/host.
3. **Adopt Planner-Executor Model Tiering for Agentic Coding:** Pairing a high-reasoning planner to generate verifiable step checklists with a fast, low-cost execution model like Gemini 4 Hydrogen ($1.50/$7.50 per 1M tokens, 2.5x faster than 3.8 Flash) preserves frontier accuracy while cutting quota usage by ~24% and completion time by 19%.
