**Industry & Architecture Takeaways:**
1. **Replace Verbose Agent Transcripts with Verified, Bounded Handoff State:** Storing raw session logs bloats context and compounds stale-state errors. Long-horizon agents should persist only compact, goal-oriented state files (~40K chars rather than 1M-char logs) and run a lightweight transcript-verification pass before committing memory updates.
2. **Harden Sandbox Proxy Surfaces and Move to Continuous Embedded Safety Audits:** As autonomous exploit frameworks emerge and regulatory scrutiny intensifies over sandbox escapes, internal package proxies and dependency mirrors must be treated as untrusted egress surfaces, while safety evaluations require realistic production-like environments to avoid alignment-eval detection.
3. **Price and Architect B2B APIs for Cost-Sensitive Agent Callers:** Unlike human seat holders, autonomous agents inspect per-call unit costs in real time and aggressively route away from expensive endpoints. Combining hybrid retrieval (native BM25 + quantized vectors) with transparent per-call agent pricing protects both margins and retention.
