**Industry & Architecture Takeaways:**
1. **Migrate Workspace Agents to Managed MCP Servers Before February 2027:** Google Workspace's GA MCP servers and CLI—paired with Anthropic's Skills over MCP, Tasks, and Elicitation—establish MCP as the mandatory control plane for agent OAuth identity (`is_agentic`), HITL confirmation rules, and admin audit logs.
2. **Offload Routing & Classification to Calibrated Decision Models:** AWS Strands Decider v2 shows that single-forward-pass, prefix-bidirectional models (2B–31B) can handle tool selection, guardrails, and small-vs-large model routing at 94% of frontier accuracy for 44% of the cost without autoregressive token bloat.
3. **Test Everyday Consistency Across Input Variations, Not Single-Shot Peaks:** DeepMind's Humanity's First Exam (544 four-way consistency sets) demonstrates that models scoring 95%–98% on single tries still drop to 85%–91% under slight prompt or visual variations, making multi-variation regression suites essential before trusting unattended workflows.
